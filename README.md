# Data Engineering kurs

Ovo je repozitorijum za vežbe, domaće zadatke i projekte sa IT Bootcamp.a Data Engineering kursa.
Struktura repozitoruijuma će se osvažavati svakodnevno, a prema tome i ovaj fajl.

## U okviru repozitorijuma dodati su folderi:
    1. Vežbe
    2. Domaći zadaci
    3. Projekti
    4. ...

## O kursu:

Tokom Data Engineering kursa očekujem da obradim sledeće teme:

- Napredno korišćenje Pythona i SQL-a za obradu i analizu podataka.
- Projektovanje i automatizaciju ETL/ELT procesa.
- Rad sa velikim skupovima podataka korišćenjem Apache Spark-a i Databricks-a.
- Učenje rada sa Git-om i GitHub-om.
- Upoznavanje sa alatima za obradu i čuvanje podataka.
